# Projeto-Integrado-Conect

Projeto Integrado Conect

English

This is a college project to build a system for managing the operations of an internet service provider. Development will continue throughout the course, from requirements and design to a working application.
Planned features
- Customer and contract management
- Internet plans, subscriptions, plan changes, cancellations, and billing
- Purchases, suppliers, equipment, and inventory
- Software and firmware license records
- Service orders and field maintenance
- Network incident records, including fiber cuts
- Notifications about service interruptions and billing
- Reports on sales and cancellations, operating expenses, overdue payments, and network availability by Point of Presence (POP)
These features describe the planned scope. They have not necessarily been implemented yet.
Development
Requirements, design documents, code, and tests will be added as the project develops. The technology stack is still to be defined.
Privacy
Fictional data in examples and tests.

Português (Brasil)

Este é um projeto acadêmico para desenvolver um sistema de gestão das operações de uma provedora de internet. O trabalho será desenvolvido ao longo do curso, desde os requisitos e a modelagem até uma aplicação funcional.
Funcionalidades previstas
- Cadastro de clientes e contratos
- Planos de internet, adesões, alterações, cancelamentos e faturamento
- Compras, fornecedores, equipamentos e estoque
- Registro de licenças de software e firmware
- Ordens de serviço e manutenção em campo
- Registro de ocorrências na rede, incluindo rompimentos de fibra
- Notificações sobre interrupções de serviço e cobranças
- Relatórios de vendas e cancelamentos, gastos operacionais, inadimplência e disponibilidade da rede por Ponto de Presença (POP)
Esses itens representam o escopo planejado e não significam que todas as funcionalidades já estejam implementadas.
Desenvolvimento
Os requisitos, documentos de projeto, código e testes serão adicionados conforme o sistema evoluir. As tecnologias ainda serão definidas.
Privacidade
Dados fictícios nos exemplos e testes.
