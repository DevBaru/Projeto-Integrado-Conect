# Projeto-Integrado-Conect
Conect Integrated Project
This is a long-term college project to develop a system for managing an internet service provider's operations. The work will progress throughout the course, from requirements and design to a functional application.

Planned scope
- Customer and contract management
- Plans, subscriptions, changes, cancellations, and billing
- Purchases, suppliers, equipment, and inventory
- Software and firmware license records
- Service orders and field maintenance
- Records of network incidents, such as fiber cuts
- Notifications about service interruptions and billing
- Operational reports for the NOC team, including sales and cancellations, expenses, overdue payments, and network availability by Point of Presence (POP)
The features listed above describe the planned scope. They are not a statement that the system has already been implemented.

Development

Requirements, design decisions, source code, and tests will be added as the project progresses. The technology stack has not been decided yet.

Privacy and security

Do not commit student registration numbers (RA), personal details, customer records, contracts, invoices, passwords, API keys, access tokens, private configuration files, or other confidential information.

Use fictional data in examples and tests. Check documents, screenshots, and file metadata before publishing them. Keep local secrets in environment files that are excluded from version control. If a credential is exposed, revoke or rotate it immediately; removing it in a later commit does not erase it from the repository history.
