# Projeto Integrado Conect

## English

This college project that aims to develop a system to manage the operations of an internet service provider. The project will grow throughout the course, from requirements and design to a functional application.

### Planned scope

- Customer and contract management
- Internet plans, subscriptions, changes, cancellations, and billing
- Purchasing, suppliers, equipment, and inventory
- Software and firmware license records
- Service orders and field maintenance
- Network incident records, including fiber cuts
- Notifications about service interruptions and billing
- Reports on sales and cancellations, operating expenses, overdue payments, and network availability by Point of Presence (POP)

These features are part of the planned scope and may not be implemented yet.

### Development

Requirements, design documents, source code, and tests will be added as the project progresses. The technology stack has not been defined yet.

### Privacy

Fictional data in examples and tests.

## Português (Brasil)

Este projeto acadêmico tem como objetivo desenvolver um sistema para gerenciar as operações de uma provedora de internet. O trabalho será desenvolvido ao longo do curso, desde os requisitos e a modelagem até uma aplicação funcional.

### Escopo previsto

- Cadastro de clientes e contratos
- Planos de internet, adesões, alterações, cancelamentos e faturamento
- Compras, fornecedores, equipamentos e estoque
- Registro de licenças de software e firmware
- Ordens de serviço e manutenção em campo
- Registro de ocorrências na rede, incluindo rompimentos de fibra
- Notificações sobre interrupções de serviço e cobranças
- Relatórios de vendas e cancelamentos, gastos operacionais, inadimplência e disponibilidade da rede por Ponto de Presença (POP)

Essas funcionalidades fazem parte do escopo planejado e podem ainda não estar implementadas.

### Desenvolvimento

Os requisitos, documentos do projeto, código-fonte e testes serão adicionados conforme o trabalho avançar. As tecnologias ainda serão definidas.

### Privacidade

Dados fictícios nos exemplos e testes.
